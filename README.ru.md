# Gift Unwrap: концепт для коллекционных подарков Telegram

[English](README.md)

Новый коллекционный подарок приходит в чат обычным сообщением-подарком, только вместо картинки в нём
маленькая стеклянная сфера, перевязанная лентой в цветах подарка. Тапаешь по сообщению — сфера
поднимается в центр экрана, появляется подсказка **Pull the ribbon to unwrap**, и палец один раз
показывает жест: прижимает кончик ленты и тянет вниз. Тянешь сам — стекло растягивается, дрожит,
трескается и разлетается. Фон подарка заливает экран, его символ ровным узором заполняет всё поле
волной от подарка к краям, и поднимается обычная карточка подарка Telegram с настоящими атрибутами
и их редкостью.

- **Show on Profile** делает подарок публичным. Он улетает в профиль, встаёт в кольцо коллекционных
  подарков, которое вращается вокруг аватара как кольца Сатурна, а шапка профиля перекрашивается в
  его фон и символ. Подтверждает это родной тост Telegram.
- **Keep Private** — это когда просто закрываешь карточку. Подарок остаётся твоим, но видишь его
  только ты («Only you can see this gift for now»). Показать его в профиле можно позже со страницы
  подарка.

Эффект не привязан к одному подарку. Он берёт данные любого коллекционного подарка: анимацию модели,
символ, цвета фона (`center / edge / pattern / text`), номер, редкость каждого атрибута и тираж. В
демо настоящие подарки: Jingle Bells «Ice Chime» на фоне Cobalt Blue, а на орбите Plush Pepe,
Durov's Cap, Heart Locket, Precious Peach и Toy Bear.

## Что внутри

```
ios/                    проект Xcode (iOS 16+): демо-приложение + Kit
  GiftUnwrap/Kit/       сам эффект (UIKit + SceneKit + AVFoundation), без зависимостей
  GiftUnwrap/Demo/      чат → распаковка → профиль, как в видео
android/                проект Android Studio (minSdk 24, Java)
  giftunwrap/           эффект в виде библиотеки (Views + Canvas), без зависимостей
  app/                  демо-приложение + FlowRenderTest
TelegramIntegration/
  ios/                  модуль GiftUnwrapScreen + install.py для Telegram-iOS
  android/              GiftUnwrapOverlay + install.py для Telegram-Android
```

## Как запустить

**iOS:** открой `ios/GiftUnwrap.xcodeproj`, выбери симулятор iPhone или телефон и нажми Run (⌘R).
Чтобы сценарий проигрался сам, включи аргумент запуска `-autoplay` (Product → Scheme → Edit
Scheme → Run → Arguments).

**Android:** открой папку `android/` в Android Studio и запусти `app` или установи
`media/GiftUnwrap_demo.apk`.

В обоих демо тап по профилю запускает сценарий заново.

## Как встроить в Telegram

Для каждой платформы одна команда, она меняет три места в коде Telegram. Подробности — в
`TelegramIntegration/*/INTEGRATION.md`.

```sh
python3 TelegramIntegration/ios/install.py     /путь/к/Telegram-iOS
python3 TelegramIntegration/android/install.py /путь/к/Telegram-Android
```

Адаптеры берут настоящие данные подарка, **Show on Profile** вызывает настоящий запрос сохранения
(`updateStarGiftAddedToProfile` / `saveStarGift`) и показывает родной тост. Если закрыть, подарок
остаётся скрытым. Повторные тапы открывают обычную карточку подарка.

## Анимация

- Каждая анимация — функция времени на часах дисплея, поэтому её можно прервать, и она
  повторяется одинаково. Пружины и кривые взяты из Telegram: bounce 5/900/88, menu 5/900/104,
  sheet 5/900/124 и кривая `tg` bezier(0.38, 0.7, 0.125, 1).
- Палец-подсказка нажимает, тянет на 74 pt и отпускает на пружине каждые 4,2 с, пока ты сам не
  коснёшься ленты.
- Лента идёт за пальцем 1:1, в сторону — с резиновым сопротивлением. После отпускания решает
  проекция инерции, как у Apple: если бросок доносит ленту до конца, стекло лопается, если нет —
  лента пружиной возвращается.
- Узор — ровная шестиугольная сетка из символа подарка по всему фону с мягким окном вокруг
  подарка. Он появляется волной от подарка со скоростью 900 pt/с, каждый символ на пружине.
- Вибрация усиливается ступенями вместе с натяжением. Звуки синтезируются в коде, аудиофайлов нет,
  и они слушаются беззвучного режима.

## Что проверено

- **Android:** проект собирается, debug-APK собран. `FlowRenderTest` проходит демо настоящими
  касаниями: тап по сообщению, подсказка, рывок ленты, **Show on Profile**. Каждый кадр рисует
  графика самого Android, тест проверяет, что стекло лопнуло и открылся профиль. Видео Android
  сделано из этих кадров.
- **iOS:** проект собирается и работает в Xcode 27 на симуляторе iPhone 18 Pro (iOS 27). Весь
  сценарий пройден в симуляторе: сообщение, подсказка, стекло, фон и карточка, **Show on Profile**,
  полёт на орбиту, перекраска шапки и тост.
- **Адаптеры для Telegram:** установщики прогнаны на свежих исходниках Telegram-iOS и
  Telegram-Android. Сами адаптеры собираются только внутри проектов Telegram, там их ещё не
  собирали.
